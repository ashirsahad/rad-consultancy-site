# Fast deploy (Vercel / Netlify)

**Vercel (drag & drop)**
1. Go to https://vercel.com/new → **Upload**.
2. Drag this entire folder or the `rad-vercel.zip` file.
3. Deploy → you'll get a live URL instantly.
   - Pretty URLs like `/contact` work via `vercel.json` routes.

**Netlify (drag & drop)**
1. Go to https://app.netlify.com/drop
2. Drop this folder or `rad-netlify.zip`.
3. Live URL appears; pretty URLs are enabled via `netlify.toml` and `_redirects`.

Optional: connect a custom domain in platform settings.
